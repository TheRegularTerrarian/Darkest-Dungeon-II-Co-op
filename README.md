  Setup Guide

  1. Download the .exe and double click it to run it

  2. Open Darkest Dungeon II from Steam and go to the main menu

  3.   For hosts, press F9 to open a lobby, and F10 to invite your friends on Steam

  4.   If this fails, find the lobby ID in the doorstop log file in the folder in your DD2 Steam Folder. It should be "lobby={id}"

  5.   For players, press F7 and paste the code into the Join bar under the Lobby tab presuming accepting the invite doesn't work

  6.   Either way, you will want to press F7 to open the menu that will allow you to vote, control your hero, etc

  7.   For players to see things visually, the host will have to stream the game in a discord vc or something similar

  8.   Should be all done and ready to play
